Principais comandos do Git

Lista de comandos essenciais para começar a trabalhar com controle de versão.

Inicialização e configuração

  • git init - Inicializa um repositório Git na pasta atual.
  • git clone <url> - Clona um repositório remoto para a máquina local.
  • git config --global user.name "Seu Nome" - Define o nome do autor.
  • git config --global user.email "seu@email.com" - Define o e-mail do autor.

Trabalho com arquivos

  • git status - Mostra o estado dos arquivos do repositório.
  • git add <arquivo> - Adiciona um arquivo ao staging.
  • git add . - Adiciona todos os arquivos modificados ao staging.
  • git rm <arquivo> - Remove um arquivo do repositório e do diretório.

Commit e histórico

  • git commit -m "mensagem" - Cria um commit com uma mensagem descritiva.
  • git log - Exibe o histórico de commits.
  • git log --oneline - Mostra o histórico em uma linha por commit.
  • git diff - Exibe as diferenças entre arquivos modificados e o último commit.

Branches e merge

  • git branch - Lista as branches existentes.
  • git checkout -b <nome> - Cria e troca para uma nova branch.
  • git checkout <nome> - Troca para uma branch existente.
  • git merge <nome> - Mescla uma branch na branch atual.

Repositório remoto

  • git remote -v - Lista os repositórios remotos configurados.
  • git push origin <branch> - Envia alterações para o repositório remoto.
  • git pull origin <branch> - Atualiza a branch local com mudanças do remoto.
  • git fetch - Busca atualizações do remoto sem mesclar.

Desfazer e corrigir

  • git restore <arquivo> - Restaura um arquivo para o último estado commitado.
  • git reset --hard HEAD - Descarta todas as alterações locais.
  • git revert <hash> - Cria um commit que reverte um commit anterior.
  • git stash - Guarda alterações temporariamente sem fazer commit.
Dica: use git status com frequência para acompanhar o estado do seu projeto e manter o controle das alterações antes de realizar commits.
