DIT

Principais comandos DIT

Esta página apresenta, de forma didática, os principais comandos usados em DIT, com explicação breve e exemplos práticos para facilitar o entendimento.

INSERT

Inserir dados

Usado para adicionar novos registros em uma tabela.

INSERT INTO clientes (nome, email) VALUES ('Ana', 'ana@email.com');
SELECT

Consultar dados

Permite visualizar informações armazenadas e filtrar os resultados.

SELECT nome, email FROM clientes WHERE status = 'ativo';
UPDATE

Atualizar registros

Altera valores já existentes em uma tabela.

UPDATE clientes SET email = 'nova@email.com' WHERE id = 5;
DELETE

Excluir dados

Remove registros da tabela, desde que a condição seja especificada.

DELETE FROM clientes WHERE id = 10;
CREATE

Criar tabelas

Define uma nova estrutura de armazenamento de dados.

CREATE TABLE produtos (id INT PRIMARY KEY, nome VARCHAR(100));
ALTER

Modificar estrutura

Permite alterar colunas, tipos e propriedades de uma tabela existente.

ALTER TABLE produtos ADD preco DECIMAL(10,2);
DROP

Excluir estrutura

Remove completamente uma tabela ou objeto do banco de dados.

DROP TABLE produtos;
WHERE

Filtrar resultados

Restringe os registros retornados com base em condições específicas.

SELECT * FROM clientes WHERE cidade = 'Recife' AND ativo = 1;
ORDER BY

Ordenar resultados

Organiza os dados de acordo com uma coluna escolhida.

SELECT * FROM clientes ORDER BY nome ASC;

Resumo rápido

  • INSERT: adiciona novos registros.
  • SELECT: consulta e mostra dados.
  • UPDATE: altera informações já existentes.
  • DELETE: remove registros.
  • CREATE/ALTER/DROP: controlam a estrutura das tabelas.
  • WHERE/ORDER BY: ajudam a filtrar e organizar os resultados.
